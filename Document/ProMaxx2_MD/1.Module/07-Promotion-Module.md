# QA Test Plan — โมดูล Promotion Engine (ส่งเสริมการขาย)

> ProMaxx 21.0.0-beta.1
> วันที่สร้าง: 17 สิงหาคม 2569

---

## 1. ภาพรวมโมดูล

โมดูล Promotion Engine รับผิดชอบการจัดการโปรโมชันและส่งเสริมการขาย

### 1.1 โครงสร้างโมดูล

```
Promaxxs.Promotion.Engine
├── Promotion List        ─── รายการโปรโมชัน
├── Discount Rules        ─── กฎส่วนลด
├── Bundle Promotion      ─── โปรโมชันแบบชุด
└── Member Promotion      ─── โปรโมชันสำหรับสมาชิก
```

## 4. Regression Test Checklist

- [ ] สร้าง/แก้ไข/ลบ โปรโมชันได้ถูกต้อง
- [ ] เปิด/ปิด โปรโมชันทำงานถูกต้อง
- [ ] ส่วนลด % คิดถูกต้อง
- [ ] ส่วนลด เงินคงที่ คิดถูกต้อง
- [ ] Buy X Get Y ทำงานถูกต้อง
- [ ] โปรโมชันตามช่วงเวลาทำงานถูกต้อง
- [ ] โปรโมชันสมาชิกทำงานถูกต้อง
- [ ] จำนวน Used นับถูกต้อง
- [ ] โปรโมชันซ้อนกันได้/ไม่ได้ตามกฎ
- [ ] ราคาสุดท้ายถูกต้องหลังหักโปรโมชัน
