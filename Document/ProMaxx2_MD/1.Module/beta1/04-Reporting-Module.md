# QA Test Plan — โมดูล Reporting (รายงาน)

> ProMaxx 21.0.0-beta.1
> วันที่สร้าง: 17 สิงหาคม 2569

---

## 1. ภาพรวมโมดูล

โมดูล Reporting รับผิดชอบการสร้างและส่งรายงานทุกประเภทของระบบ ใช้ FastReport Engine สำหรับ Report Generation

### 1.1 โครงสร้างโมดูล

```
Promaxxs.Modules.Reporting
├── Daily Summary         ─── สรุปยอดขายรายวัน
├── Sales Report          ─── รายงานยอดขาย
├── Profit Report         ─── รายงานกำไร
├── Email Report          ─── ส่งรายงานทางอีเมล
└── Custom Reports        ─── รายงานอื่นๆ ผ่าน FastReport
```

### 1.2 Report Engine

- **FastReport** - Report generation engine
- **FastReport.OpenSource.Export.PdfSimple** - Export PDF
- **FastReport.Compat** - Compatibility layer
- **Templates/Receipt.frx** - เทมเพลตใบเสร็จ

## 2. รายงานที่รองรับ

### 2.1 รายงานหลัก

| รายงาน | ReportFile | ReportText | รูปแบบ |
|--------|------------|------------|--------|
| ยอดขายสูงสุด-ต่ำสุด ตามมูลค่า | ✓ | - | File |
| ยอดขายสูงสุด-ต่ำสุด ตามจำนวน | ✓ | - | File |
| กำไรเบื้องต้นตามต้นทุนหลัก | ✓ | - | File |
| สรุปยอดขายประจำวัน | ✓ | ✓ | File + Text |

### 2.2 Configuration (`ui_amail.ini`)

```ini
[ReportFiles]
1 = ยอดขาย สูงสุด-ต่ำสุด ตามมูลค่าขาย
2 = ยอดขาย สูงสุด-ต่ำสุด ตามจำนวนสินค้า
3 = กำไรเบื้องต้นตาม ต้นทุนหลักของระบบ
4 = สรุปยอดขายประจำวัน

[ReportTexts]
4 = สรุปยอดขายประจำวัน
```

## 9. Regression Test Checklist

- [ ] รายงานทุกประเภทสร้างได้สำเร็จ

- [ ] Export Excel ไฟล์ถูกต้องครบถ้วน
- [ ] ส่งอีเมลรายงานได้สำเร็จ
- [ ] CC Email ทำงานถูกต้อง
- [ ] ใบเสร็จพิมพ์ครบถ้วน (วันที่, รายการ, ราคา, VAT, ส่วนลด)
- [ ] รายงานรองรับภาษาไทย
- [ ] FastReport Template ทำงานถูกต้อง
