# QA Test Plan — โมดูล Person (บุคคล/ลูกค้า/พนักงาน)

> ProMaxx 21.0.0-beta.1
> วันที่สร้าง: 17 สิงหาคม 2569

---

## 1. ภาพรวมโมดูล

โมดูล Person รับผิดชอบการจัดการข้อมูลบุคคลที่เกี่ยวข้องกับระบบ ประกอบด้วย 3 กลุ่มหลัก

### 1.1 โครงสร้างโมดูล

```
Promaxxs.Modules.Person
├── Customer        ─── จัดการข้อมูลลูกค้า
│   ├── Category        ─── กลุ่มลูกค้า
│   └── AccountChart    ─── แผนภูมิบัญชี
├── Staff           ─── จัดการข้อมูลพนักงาน
└── Supplier        ─── จัดการข้อมูลซัพพลายเออร์
```

## 6. Regression Test Checklist

- [ ] เพิ่ม/แก้ไข/ลบ ลูกค้าได้ถูกต้อง
- [ ] เพิ่ม/แก้ไข/ลบ พนักงานได้ถูกต้อง
